Privacy Policy - Discord Chat Exporter

Last updated: April 30, 2026

Overview

Discord Chat Exporter exports Discord channel or DM messages from the Discord web app into local CSV, JSON, or HTML files. This policy explains what the extension accesses and what it does not collect.

Data We Do Not Collect

  • We do not collect your Discord chat history.
  • We do not collect or store your Discord token.
  • We do not collect your Discord account credentials.
  • We do not sell, share, or transmit exported chat files.
  • We do not run extension analytics or advertising trackers.

Local Processing

Messages are fetched and formatted inside your browser. Exported files are created locally and downloaded by the browser. Chat content is not uploaded to ExtPilot servers.

Discord Token Handling

The extension reads the Discord web app token only during the active export flow to request message history from Discord. The token is used in memory only and is not written to extension storage.

Storage

The extension may store settings, license status, review prompt state, and export preferences in browser extension storage. Pro users may store a license key locally so the extension can remember activation status.

Network Requests

  • Discord requests: used to fetch messages from the current Discord channel or DM during export.
  • License verification: Pro users may send a license key to ExtPilot's license server. Chat history is not sent with this request.

Permissions

The extension requests browser permissions required to run on Discord, store local settings, and download generated files. Host access is limited to Discord domains required for the product.
