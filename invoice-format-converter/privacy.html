发票格式转换器隐私政策

Last updated: 2026-06-19

发票格式转换器用于把用户主动选择的电子发票 PDF 本地转换为 OFD、XML 压缩包和 PDF。插件不会上传用户的发票 PDF、OFD 或 XML 内容。

处理的数据

插件读取用户主动选择的 PDF 文件，并在本地解析发票号码、购买方、销售方、金额等字段，用于生成 XML 和界面摘要。

权限说明

  • storage：保存 Basic 下载次数、License 激活状态和安装状态。
  • downloads：将生成的 OFD、XML 压缩包和 PDF 保存到用户设备。
  • license-worker.hellopipichong.workers.dev：用于 License Key 验证和授权状态。

不会做的事

  • 不会上传发票文件。
  • 不会出售或共享发票内容。
  • 不会把生成的 OFD / XML / PDF 发到第三方服务器。

付款和授权

Pro 购买由 Stripe 处理。License 验证会向 ExtPilot 授权服务发送 License Key 和产品 ID，不包含发票文件。
