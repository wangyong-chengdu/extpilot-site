IG Follower Exporter is a Chrome and Edge extension that exports Instagram followers and following lists you can already access to CSV or Excel. It captures usernames, display names, profile URLs, and verification status in Quick mode (up to 600 records free), or public profile fields such as email, phone, bio, follower count, business category, city, and WhatsApp number in Detailed mode when those fields are visible. Pro starts at $3.9 per month or $29/year and uses Stripe credit card checkout. Rate limiting and checkpoint resume help long exports recover from interruptions. Export processing runs locally in your browser; exported data is not uploaded to ExtPilot servers.

Last updated: September 18, 2026. Verified against: the live Edge Add-ons listing, the manual install package (v1.0.4), product privacy policy, and the current extension workflow. IG Follower Exporter cannot bypass Instagram privacy restrictions or export private follower lists you cannot already view.

Install on Chrome (Manual, ~2 Minutes)

Our Chrome Web Store listing is temporarily under review. Until it returns, install the exact same extension from our official package:

  1. Download the extension ZIP file (v1.0.4) and save it to your computer.
  2. Unzip it: right-click the file and choose Extract All... (Windows), or double-click it (Mac). Remember the folder it creates.
  3. Open Chrome, paste chrome://extensions/ into the address bar, and press Enter.
  4. Turn on the Developer mode switch in the top-right corner.
  5. Click Load unpacked (appears at the top-left).
  6. Select the folder you extracted in step 2 — the one containing manifest.json — and confirm. Do not select the ZIP file itself.
  7. Done. Click the puzzle-piece icon in Chrome’s toolbar to pin IG Follower Exporter. If you have a Pro license, open the extension → Settings → paste your License Key → click Activate.

Keep Developer mode switched on — turning it off disables manually installed extensions. Edge users can install directly from Microsoft Edge Add-ons.

Does exporting Instagram followers get your account banned?

IG Follower Exporter includes rate limiting and checkpoint resume to reduce interruption risk, but no automation tool can guarantee zero account risk. Use it only on profiles and lists you can already access, avoid excessive export frequency, and follow Instagram's terms.

Can I export Instagram followers with email addresses?

In Detailed mode, IG Follower Exporter can include public email, phone, WhatsApp number, bio, and business category when those fields are visible on the profile. Private or hidden contact fields cannot be exported.
