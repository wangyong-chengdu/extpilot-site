BrandBatch Privacy Policy

Last updated: 2026-09-16

BrandBatch batch-applies logos, watermarks, end cards, transitions and background music to your videos entirely inside your browser. The extension never uploads any of your video, image, or audio files.

What stays on your device

Imported media, rendered outputs, branding kits, and queue history are stored locally in your browser (chrome.storage.local and local downloads). They never pass through any server.

Permissions

The extension requests only the storage permission, used to save your branding kits and preferences. No host permissions, no content scripts, no remote code.

Network requests (all optional, no personal identifiers)

Feature configuration & anonymous heartbeat — on startup the extension fetches a small configuration JSON from license.extpilot.com. The request includes only the first 8 characters of an anonymous random install ID and the extension version, used for phased feature rollout and anonymous activity counts.

License verification (Pro only) — if you purchase the optional Pro upgrade, the license key string is sent to license.extpilot.com for validation. Nothing else is sent. Results are cached locally with a 14-day grace period, so Pro keeps working offline.

Optional analytics — disabled by default. If you explicitly enable it in the extension footer, anonymous usage events (e.g. "batch submitted", "output downloaded") are reported without file names, page content, or personal identifiers. You can turn it off at any time.

What we never do

We never collect or upload your videos, assets, or outputs; never collect browsing history or personal identity information; never sell or share data with third parties for marketing; never require an account.

Payments

Pro purchases are processed by Stripe. We never see or store your card details; Stripe returns a license key directly to you.

Data deletion

Remove the extension from your browser at any time to delete all local data (kits, queue history, install ID). Opt-in analytics can be disabled at any time in the extension footer.
